Образ (image) — это неизменяемый шаблон, из которого создаются контейнеры. Внутри он устроен как стопка слоёв (layers), каждый из которых фиксирует изменения файловой системы относительно предыдущего.

Посмотреть слои конкретного образа можно командой: `docker image inspect nginx --format '{{json .RootFS.Layers}}'`.

Слои хранятся на диске один раз. Если два образа используют одинаковый базовый слой, Docker не дублирует его — оба образа ссылаются на одни и те же данные. Это называется совместное использование слоёв (layer sharing).
