Командная строка (CLI) — общий способ взаимодействия с программой (компьютером) через текстовые команды.

Terminal — программа, предоставляющая интерфейс для работы с командной оболочкой (shell).

Shell (оболочка) — это программа, которая принимает команды пользователя, разбирает их и выполняет встроенные команды или запускает другие программы.

Bash (Bourne Again SHell) — одна из наиболее распространённых командных оболочек, особенно в Linux. Zsh, Fish и Dash — другие командные оболочки. При запуске терминала в стандартной конфигурации терминал автоматически запускает оболочку, настроенную для пользователя по умолчанию.

Когда вы нажимаете Enter, bash выполняет несколько шагов:
1. Читает введённую команду.
2. Разбирает её: команды, аргументы, операторы, переменные, перенаправления и т. д.
3. Определяет, что нужно выполнить: alias, функцию, встроенную команду Bash или внешнюю программу.
4. Если это внешняя программа, Bash ищет её в каталогах из PATH.
5. Запускает программу и передаёт ей аргументы.
6. Если команда запущена в обычном режиме, Bash ждёт её завершения и получает код завершения. Если команда запущена в фоне, Bash продолжает работу, не дожидаясь её завершения.
7. Показывает prompt и ждёт следующую команду.

Приглашение ввода (prompt) — строка, которую bash показывает, когда готов принять следующую команду. В стандартной конфигурации знак $ обычно используется для обычного пользователя, а # — для пользователя root (суперпользователь). Это часть оформления prompt и может быть изменено.

Bash не знает о каждой программе в системе заранее. Если команда не является alias, функцией или встроенной командой, Bash ищет соответствующий исполняемый файл в каталогах, перечисленных в переменной PATH. Если исполняемый файл найден — Bash запускает его. Если нет — вы увидите сообщение об ошибке.

Проверить, где находится исполняемый файл команды, можно с помощью which <имя команды>.

type <имя команды> — показывает, как Bash интерпретирует указанное имя: как alias, функцию, встроенную команду или внешнюю программу.

Bash умеет работать в двух режимах. Интерактивный режим — это то, с чем вы работаете в терминале: вводите команды вручную, получаете ответ. Неинтерактивный режим используется, когда Bash выполняет команды без непосредственного взаимодействия с пользователем, например при запуске скрипта. Оба режима используют один и тот же синтаксис.
