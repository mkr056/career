Архивирование (archiving) — это упаковка нескольких файлов и каталогов в один файл без изменения их содержимого. Архив удобно передавать, хранить и резервировать. В Linux для этого используют утилиту tar (Tape ARchive).

Важно понимать разницу с самого начала: tar только собирает файлы в один контейнер, но не сжимает их. Сжатие — отдельная операция.

Команда tar управляется флагами. Для создания архива нужны три основных:
- -c: Создать новый архив (create)
- -f: Указать имя файла архива (file)
- -v: Подробный вывод: показывать каждый добавляемый файл (verbose)

Синтаксис команды: `tar -cvf имя_архива.tar файл1 файл2 каталог1`.

Порядок важен: после -f сразу идёт имя архива, затем перечисляются источники.

Также можно создать архив из целого каталога передав путь.

Ошибки:
- Запустить команду без -f. Без этого флага tar попытается работать с устройством /dev/tape, что на обычной машине завершится ошибкой.
- Не указать расширение .tar. Технически это не обязательно — tar не проверяет расширение. Но соглашение .tar помогает сразу понять, что перед вами архив, и упрощает работу в команде.

Обратная операция — извлечение файлов из архива — строится на флаге -x (от английского extract).

По умолчанию tar извлекает файлы туда, где вы находитесь. Чтобы указать другое место, используют флаг -C (от change directory). Каталог должен существовать заранее — tar его не создаёт автоматически.

tar позволяет извлечь не весь архив, а только конкретный файл — достаточно указать его имя в конце команды.

Архив, созданный командой tar, не сжимается автоматически — он просто объединяет файлы в один. Чтобы уменьшить размер, используют сжатие (compression). Стандартный инструмент для этого в Linux — gzip.

gzip сжимает один файл и заменяет его сжатой версией с расширением .gz. Исходный файл при этом удаляется.

Чтобы проверить степень сжатия, используют флаг -v (verbose). Число показывает, насколько уменьшился файл.

gunzip — обратная операция: распаковывает .gz-файл и восстанавливает оригинал.

После этого снова появится report.txt, а файл .gz исчезнет. Альтернативный способ — gzip -d (флаг -d означает decompress).

На практике tar и gzip почти всегда используют вместе. Вместо двух отдельных шагов (сначала создать архив, потом сжать) tar умеет делать всё сразу с помощью флага -z.

Распаковка .tar.gz выполняется заменой -c на -x.

Расширение .tar.gz иногда записывают в сокращённой форме .tgz — это один и тот же формат, команды работают с ним одинаково.

Zip-архив (zip archive) — один из самых распространённых форматов упаковки файлов. В отличие от tar, команда zip одновременно и объединяет файлы в один контейнер, и сжимает их. Это делает её удобной для быстрого обмена файлами, особенно с пользователями Windows и macOS, где формат zip поддерживается «из коробки».

Базовый синтаксис: `zip имя_архива.zip файл1 файл2 ...`.

Первый аргумент — имя создаваемого архива, все последующие — файлы, которые нужно в него поместить. Расширение .zip можно не указывать, но лучше добавлять явно — так сразу понятно, что за файл перед вами.

Оригинальные файлы при этом не удаляются — zip по умолчанию оставляет исходники нетронутыми.

Если попробовать передать в zip имя каталога без дополнительных флагов, команда добавит только сам каталог как запись, но проигнорирует его содержимое. Чтобы упаковать каталог рекурсивно (recursively) — то есть вместе со всеми вложенными файлами и подкаталогами — используют флаг -r

Если архив уже создан, можно дописать в него новые файлы той же командой — zip автоматически обновит существующий архив, а не перезапишет его.

Прежде чем извлекать файлы, полезно убедиться, что архив содержит именно то, что ожидается. Флаг -l (от английского list) выводит список файлов внутри архива без их извлечения: `unzip -l archive.zip`.

Чтобы извлечь все файлы из архива в текущий каталог, достаточно: `unzip archive.zip`.

unzip воссоздаёт структуру каталогов, которая была при создании архива.

Чтобы не засорять текущую директорию, используйте флаг -d (destination) с указанием целевого каталога. Если каталог не существует, unzip создаст его автоматически.

Иногда из большого архива нужен только один файл. Укажите его имя явно.
