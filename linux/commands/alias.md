Команда alias позволяет создать псевдоним — короткое имя, которое подставляется вместо указанной команды.

Базовая форма записи: `alias имя='команда'`. Важно: пробелы вокруг знака = недопустимы.

Чтобы увидеть все активные псевдонимы текущего shell: `alias`

Для удаления псевдонима используется `unalias <алиас>`.

Псевдоним, созданный с помощью alias непосредственно в терминале, существует только в текущем shell-процессе. После его завершения псевдоним исчезает.

Чтобы псевдоним сохранялся при следующих запусках shell, его добавляют в файл конфигурации оболочки. Для Bash обычно используется ~/.bashrc, для Zsh — ~/.zshrc. После изменения конфигурационного файла изменения можно применить без перезапуска терминала: `source <название файла>`.
