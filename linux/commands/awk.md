Вывод ps, top и подобных команд — это таблица: значения разбиты на столбцы пробелами. Чтобы вытащить конкретное поле или отфильтровать строки по значению столбца, есть удобный инструмент — awk. Он сам режет каждую строку на поля по пробелам, и вы обращаетесь к ним по номеру: $1 — первый столбец, $2 — второй, $3 — третий и так далее. $0 — вся строка целиком.

Базовый синтаксис — `awk 'pattern {action}' файл`. Для каждой строки awk проверяет pattern (условие) и, если оно истинно, выполняет action. Чаще всего action — это print.

Если action не указан — значит по умолчанию awk печатает всю строку.

Полезно знать: awk сам пропускает лишние пробелы между полями, поэтому «USER PID COMMAND» через один или несколько пробелов разберётся одинаково. Но заголовок-строку awk тоже прочитает как обычную — учитывай это в условии (например, сравнение по значению столбца заголовок обычно отсеет само собой).

`$NF` — последнее поле; `NF` — число полей, `NR` — номер строки.

Пропустить заголовок (со 2-й строки): `awk 'NR>1' data.txt`.

Агрегация ассоциативными массивами — считать по ключу за один проход. Блок END выполняется после всех строк:
```
# сумма 2-го поля по каждому значению 1-го поля
awk '{sum[$1]+=$2} END{for (k in sum) print k, sum[k]}' data.txt

# подсчёт вхождений (аналог uniq -c, но без сортировки)
awk '{cnt[$1]++} END{for (k in cnt) print cnt[k], k}' access.log
```

Пример под реальную задачу — среднее время ответа по эндпоинту:
```
awk '{s[$1]+=$2; c[$1]++} END{for (k in s) printf "%s: %d\n", k, int(s[k]/c[k])}' api.log | sort
```

Здесь `int(x)` отбрасывает дробную часть (округление вниз). Для указанного формата вывода `printf` даёт полный контроль над разделителями.

В awk слово END — это специальный управляющий блок, который выполняется строго один раз в самом конце, когда awk полностью прочитал весь файл (или весь поток ввода).

`awk 'END { print NR }'`

awk молча читает файл строку за строкой, внутри себя считает их (NR растет), но ничего не выводит на экран. И только когда файл закончился, срабатывает блок END, который печатает финальное значение NR.
