Команда cat (сокращение от concatenate — «конкатенировать», то есть объединять). Несмотря на название, чаще всего её используют именно для вывода содержимого файла прямо в терминал. Команда читает файл целиком и выводит его в стандартный поток вывода — то есть прямо на экран.

cat умеет принимать несколько аргументов и выводит их один за другим, без разделителей.

Полезные флаги:
* -n: Нумерует все строки вывода
* -b: Нумерует только непустые строки
* -A: Показывает невидимые символы: $ в конце каждой строки, ^I вместо табуляции

cat без аргументов начнёт читать стандартный ввод (stdin): терминал будет ждать текста с клавиатуры и дублировать каждую введённую строку. Чтобы завершить ввод и выйти, нажмите Ctrl+D. Это не прерывание программы, а сигнал EOF (End of File) — признак конца потока. Ctrl+C прерывает выполнение команды.
