curl — универсальный HTTP-клиент из терминала.

Самый простой вызов: `curl https://example.com`. По умолчанию curl шлёт `GET`, печатает только тело ответа и молчит про заголовки и статус.

Важный флаг гигиены — `-s` (silent): он убирает индикатор прогресса, который curl по умолчанию пишет в stderr. В скриптах его ставят почти всегда, чтобы прогресс-бар не мешался в выводе.

Часто нужно посмотреть метаданные ответа, не скачивая тело целиком. Для этого есть два близких, но разных флага:
* `-I` шлёт запрос методом HEAD и печатает только заголовки ответа, без тела.
* `-i` делает обычный запрос и печатает заголовки ответа, а затем тело, разделённые пустой строкой — ровно так, как HTTP-ответ устроен внутри.

Первая строка вывода в обоих случаях — статус-строка вида `HTTP/1.1 200 OK`: версия, код, причина.

Чтобы увидеть обе стороны диалога (и запрос и ответ) используется флаг `-v` (verbose).

В выводе `-v` каждая строка помечена префиксом, и по нему сразу видно, чья это реплика:
- `*` — служебные сообщения самого curl (резолвинг имени, установка соединения, TLS). Это не HTTP, а «дневник» клиента.
- `>` — то, что curl отправил серверу: строка запроса и заголовки запроса.
- `<` — то, что сервер вернул: статус-строка и заголовки ответа.

По умолчанию curl шлёт минимум заголовков (`Host`, `User-Agent`, `Accept`). Чтобы отправить свои используют `-H 'Имя: значение'`. Синтаксис ровно как у заголовка в HTTP: имя, двоеточие, пробел, значение. Несколько заголовков — просто несколько флагов `-H`, по одному на каждый.

Если задать `-H` с именем заголовка, который curl шлёт сам (например `User-Agent` или `Host`), ваше значение переопределит дефолтное.

По умолчанию curl не переходит по редиректу: он покажет вам ответ 3xx и остановится. Чтобы curl автоматически сделал следующий запрос по адресу из `Location` (и так далее по цепочке, пока не дойдёт до финального ответа), добавляют `-L` (location).
