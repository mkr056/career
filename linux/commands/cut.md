cut обрабатывает файл построчно и из каждой строки извлекает указанный фрагмент. Два ключевых флага:
* -d (delimiter) — задаёт символ-разделитель, по которому строка делится на поля (fields).
* -f (field) — указывает номер поля или диапазон полей, которые нужно извлечь.

Поля нумеруются с единицы. Если разделитель не указан, по умолчанию используется символ табуляции.

cut поддерживает диапазонную запись через дефис:
* -f2: только второе поле
* -f1,3: первое и третье поля
* -f2-4: поля со второго по четвёртое
* -f3-: от третьего поля до конца строки

Если разделитель не встречается в строке, cut считает всю строку одним полем и возвращает её целиком — без предупреждений.

Ещё одна ловушка — несколько подряд идущих разделителей. cut не объединяет их в один: каждый разделитель создаёт отдельное (возможно, пустое) поле. Если данные разделены пробелами разной ширины, cut подойдёт плохо — для таких случаев лучше использовать awk.
