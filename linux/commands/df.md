df показывает, сколько места занято и свободно на каждом смонтированном разделе (mounted filesystem) — то есть на каждом диске или его части, подключённом к файловой системе.

Числа в выводе — в блоках по 1 килобайту. Читать такой вывод неудобно: нужно делить на 1 048 576, чтобы получить гигабайты. Именно для этого существует флаг -h.

Флаг -h (от human-readable) автоматически переводит размеры в удобные единицы — килобайты, мегабайты, гигабайты.

Что означают столбцы:
- Filesystem: Устройство или раздел
- Size: Общий размер раздела
- Used: Занято
- Avail: Доступно для записи
- Use%: Процент использования
- Mounted on: Точка монтирования

Если нужна информация только об одном разделе, передайте путь аргументом: `df -h /home`. Это выведет только строку с разделом, на котором находится каталог /home. Удобно, когда разделов много и полный вывод перегружен.
