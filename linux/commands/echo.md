echo — команда shell, которая выводит переданные ей аргументы в терминал, по умолчанию добавляя в конце перевод строки.

```bash
echo <текст>
```

Если текст содержит пробелы, его можно заключить в кавычки, чтобы Bash передал весь текст как один аргумент.

Используют два основных вида кавычек:
* двойные кавычки "..." — позволяют выполнять подстановку переменных
* одинарные кавычки '...' — воспринимают содержимое буквально

Bash подставляет значение переменной через знак $ и имя переменной, после чего echo выводит полученное значение. USER — обычно доступная переменная окружения, содержащая имя текущего пользователя.

Опция -n отключает добавление завершающего перевода строки.

Флаг -e включает обработку управляющих последовательностей \(спецсимволов\) \(\\n, \\t и др.\).
