Команда find это инструмент поиска в Linux, который обходит файловую систему рекурсивно и возвращает результаты по заданным критериям.

Базовый синтаксис: `find [где искать] [критерии]`.

Первый аргумент — начальная точка поиска (search path): каталог, с которого find начнёт обход. Если её не указать, поиск начнётся с текущего каталога.

Без критериев find просто перечисляет всё, что найдёт.

Флаг -name ограничивает поиск по имени файла или каталога. Значение передаётся в кавычках.

find выводит полный путь к каждому найденному объекту.

В значении -name можно использовать шаблоны (wildcards). Шаблон поддерживает глобы (glob patterns) — специальные символы подстановки. Самый распространённый — звёздочка \*, которая заменяет любое количество любых символов. ? заменяет ровно один любой символ.

Типичная ошибка — забыть кавычки вокруг шаблона с \*. Если написать -name \*.conf без кавычек и в текущем каталоге уже есть файлы .conf, оболочка подставит их имена вместо шаблона, и find получит совсем не тот аргумент, который вы ожидали. Шаблон "\*.log" обязательно берётся в кавычки — иначе оболочка раскроет его сама, до того как find получит аргумент, и результат будет непредсказуемым. ЧТО ЗНАЧИТ?

По умолчанию find уходит на неограниченную глубину. Флаг -maxdepth задаёт максимальное количество уровней вложенности.

Значение 1 означает «только непосредственное содержимое указанного каталога».

Фильтр -type ограничивает поиск определённым типом файловой системы. Два значения, которые нужны в повседневной работе:
* f: обычный файл (regular file)
* d: каталог (directory)

-name чувствителен к регистру. Когда регистр неизвестен или непредсказуем, используют фильтр -iname (case-insensitive name).

Флаг -size принимает число с суффиксом единицы измерения:
* c: байты
* k: килобайты
* M: мегабайты
* G: гигабайты

Перед числом можно поставить знак:
* без знака — точное совпадение (редко нужно на практике);
* + — больше указанного значения;
* - — меньше указанного значения.

Время модификации (modification time, mtime) — это момент, когда содержимое файла последний раз менялось. Флаг -mtime принимает число в сутках.
* -7: изменён менее 7 дней назад (за последнюю неделю);
* +30: изменён более 30 дней назад;
* 0: изменён сегодня (в течение последних 24 часов).

Если нужна точность до минут, используют -mmin. Например, -mmin -60 — изменён менее часа назад.

По умолчанию find объединяет несколько флагов через логическое И (AND). Для логического ИЛИ (OR) используют флаг -o, а условия группируют в скобках (скобки нужно экранировать):

`find /home -name "*.tmp" -o -name "*.bak"`

Для отрицания условия служит флаг !: `find . ! -name "*.txt"`.
