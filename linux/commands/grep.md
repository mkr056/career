grep (Global Regular Expression Print) — команда для поиска строк в файле, которые содержат заданный текст или шаблон.

Базовый синтаксис: `grep шаблон имя_файла`.

Если шаблон содержит пробел, его нужно взять в кавычки — иначе оболочка разобьёт его на отдельные аргументы.

grep принимает несколько файлов сразу. В этом случае перед каждой найденной строкой выводится имя файла.

По умолчанию grep воспринимает шаблон как базовое регулярное выражение (Basic Regular Expression, BRE). Для начинающих это означает, что можно искать обычный текст — и он будет найден буквально. Важно понимать: grep ищет вхождение шаблона в любом месте строки, а не строгое совпадение всей строки целиком.

По умолчанию grep различает заглавные и строчные буквы. Флаг -i (от ignore case) отключает это различие.

Флаг -n (от line number) добавляет перед каждым совпадением номер строки.

Флаг -c (от count) выводит только число строк, в которых найден шаблон. Важный нюанс: -c считает строки, а не вхождения.

Инвертированный поиск (флаг -v, от англ. invert) выводит строки, которые не содержат шаблон.

Символ ^ означает «начало строки».

Шаблон ^$ означает строку, где начало сразу совпадает с концом, то есть пустую строку.

Без флагов grep работает только с конкретными файлами. Флаг -r (recursive) заставляет его обойти весь каталог и все вложенные подкаталоги. Вывод будет содержать путь к файлу и строку с совпадением.

Когда важно знать не содержимое строк, а какие файлы содержат шаблон, используют флаг -l (list). Он подавляет вывод строк и печатает только пути к файлам.

grep -v выводит все строки, кроме подходящих. Записать этот вывод обратно в тот же файл напрямую нельзя (файл обнулится раньше, чем прочитается), поэтому идут через временный файл.

Квадратные скобки вокруг первой буквы превращают строку в регулярное выражение.
