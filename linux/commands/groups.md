Команда groups показывает, в каких группах состоит пользователь.

Сначала имя пользователя, а остальные слова — названия групп. Первая группа в списке — основная группа (primary group), остальные — дополнительные группы (supplementary groups).

Чтобы посмотреть группы другого пользователя, передайте его имя аргументом.
