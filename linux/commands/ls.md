Команда ls показывает, что находится в каталоге. ls можно также использовать с файлами.

Базовый синтаксис: `ls [флаги] [путь]`

Квадратные скобки означают, что оба аргумента необязательны. Если вызвать ls без аргументов, команда покажет содержимое текущего рабочего каталога.

Каталоги и файлы в выводе визуально неотличимы — просто список имён.

По умолчанию ls не показывает скрытые файлы (hidden files) — те, чьё имя начинается с точки. Также по умолчанию ls не выводит подробную информацию: права доступа, владельца, размер, дату изменения. Вы видите только имена.

ls принимает несколько аргументов одновременно, вывод будет разбит по секциям.

Флаг -l (от long) переключает вывод в длинный формат, где каждый файл занимает отдельную строку с несколькими полями. Поля слева направо: права доступа, количество жёстких ссылок, владелец, группа, размер в байтах, дата изменения, имя. Строка, начинающаяся с d, обозначает каталог, а с - — обычный файл.

Флаг -a (от all) включает скрытые файлы в вывод.

Флаг -h (от human-readable) автоматически переводит размеры в килобайты, мегабайты и гигабайты. Флаг -h работает только в паре с -l, потому что без подробного режима размер в выводе вообще не появляется.

По умолчанию ls сортирует файлы по имени в алфавитном порядке. Флаг -t меняет порядок: файлы выводятся от самого свежего к самому старому по дате последнего изменения. Чтобы перевернуть порядок (от старого к новому), добавляют флаг -r (reverse): `ls -ltr`.

Флаг -S (size) сортирует файлы по убыванию размера — самый большой файл окажется первым.

Флаг -R (рекурсивный просмотр) показывает полную структуру каталога.
