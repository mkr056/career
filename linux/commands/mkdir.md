Команда mkdir (от make directory) создаёт новый каталог в файловой системе. Если каталог с таким именем уже существует, mkdir выдаст ошибку. Это защита от случайного перезаписывания структуры. mkdir может принимать несколько аргументов сразу.

Флаг -p (от parents, «родительские») создаёт всю цепочку каталогов сразу, включая промежуточные. Если какой-то из них уже существует — команда просто пропустит его без ошибки
