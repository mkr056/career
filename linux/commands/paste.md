Если cut разбирает строки на части, то paste делает обратное — склеивает строки из нескольких файлов или источников в одну, располагая их рядом через разделитель.

По умолчанию paste берёт первую строку из каждого файла, объединяет их через символ табуляции и выводит как одну строку. Затем берёт вторые строки — и так до конца файлов.

Строки соединяются попарно. Если один файл короче — для недостающих строк подставляется пустая строка.

По умолчанию разделитель — табуляция. Флаг -d (delimiter) позволяет указать любой другой символ.

Можно передать несколько символов-разделителей — тогда они будут чередоваться между полями. Первый разделитель встаёт между первым и вторым файлом, второй — между вторым и третьим, затем цикл повторяется.

Флаг -s (serial) меняет поведение: вместо попарного объединения файлов paste склеивает все строки одного файла в одну строку.

paste умеет читать стандартный ввод, если вместо имени файла указать -.
