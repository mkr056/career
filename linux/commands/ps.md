Команда ps (process status) показывает снимок процессов, запущенных в системе в момент вызова. В отличие от интерактивных инструментов, ps выводит статичный список — это удобно для скриптов и быстрой проверки. Без флагов ps показывает только процессы текущего сеанса терминала.

Самая распространённая комбинация — aux. Она выводит все процессы всех пользователей в подробном формате. Ключевые столбцы:
- USER: Владелец процесса
- PID: Идентификатор процесса
- %CPU: Загрузка процессора
- %MEM: Использование памяти
- STAT: Состояние процесса (S — спит, R — выполняется, Z — зомби)
- COMMAND: Команда, которой запущен процесс

Флаги расшифровываются так: a — показать процессы всех пользователей, u — в формате с именем владельца, x — включить процессы без терминала (фоновые демоны).

Альтернативный синтаксис — -ef. Он пришёл из System V Unix и даёт похожий результат, но с одним важным дополнением: столбец PPID (Parent PID) — идентификатор родительского процесса.
