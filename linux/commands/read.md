Команда read читает одну строку из стандартного ввода (stdin) и сохраняет её в переменную. Базовый синтаксис: `read имя_переменной`.

После запуска скрипт останавливается и ждёт, пока пользователь не введёт текст и не нажмёт Enter. Всё введённое попадает в переменную, к которой затем можно обратиться через $имя_переменной.

Без подсказки пользователь видит пустой курсор и не понимает, что от него ждут. Флаг -p (от prompt — приглашение) позволяет вывести текст-подсказку перед вводом, не используя отдельный echo.

Когда нужно считать пароль или другие чувствительные данные, флаг -s (silent) отключает отображение символов на экране. Пользователь вводит пароль, но символы не отображаются. Пустой echo "" после read -s нужен, чтобы перейти на новую строку — иначе следующий вывод окажется на той же строке, что и приглашение.

Если пользователь вводит Иван Иванов, всё попадёт в одну переменную целиком. Но если указать несколько переменных через пробел (read first last), bash разобьёт ввод: first получит Иван, last — Иванов.

Также есть вариант read из файла: перенаправление ввода оператором «<». Здесь read берёт первую строку файла и кладёт её в переменную name — никакого Enter от пользователя не нужно.
