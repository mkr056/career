sed — потоковый редактор, чаще всего для замен по шаблону:
```
sed 's/foo/bar/'             # заменить первое foo на bar в каждой строке
sed 's/foo/bar/g'            # заменить все вхождения (g — global)
sed 's/ *$//'                # убрать хвостовые пробелы
sed -n '2p'                  # напечатать только 2-ю строку
sed '/^#/d'                  # удалить строки-комментарии
```

Синтаксис замены: `s/что/на_что/флаги`. Спецсимволы (`.`, `/`, `*`) при необходимости экранируются обратным слэшем.

jq — процессор JSON. Многие инструменты (docker inspect, облачные CLI, API) отдают JSON; парсить его через grep ненадёжно, а jq делает это корректно:

```
jq '.name' data.json                    # значение поля name
jq -r '.name' data.json                 # -r: без кавычек (raw)
jq '.items | length' data.json          # длина массива items
jq -r '.pods[].name' data.json          # поле name у каждого элемента массива
jq '.list | map(select(.size > 1000))'  # отфильтровать массив по условию
jq -r '.data[] | "\(.key): \(.value)"' # собрать строку из полей
```

Флаг -r (raw output) почти всегда нужен, когда результат — строка: без него jq печатает её в кавычках, и вывод не совпадёт с эталоном.
