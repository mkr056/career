Команда sort читает строки из файла или стандартного ввода и выводит их в упорядоченном виде.

По умолчанию sort сравнивает строки посимвольно, слева направо, по таблице ASCII. Это означает, что заглавные буквы идут раньше строчных, а цифры — раньше букв.

Если нужно отсортировать в обратном порядке, добавьте флаг -r (reverse).

Чтобы сортировать числа как числа, используют флаг -n (numeric sort).

Реальные данные часто выглядят как таблица с разделителями. Чтобы отсортировать по конкретному столбцу, используют флаг -k (key) с указанием номера столбца. Флаг -k принимает номер столбца, считая с единицы. По умолчанию разделителем служит пробел или табуляция; для другого разделителя добавляют -t, например -t.
