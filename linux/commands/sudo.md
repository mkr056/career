sudo (от англ. superuser do) — команда, которая позволяет запустить одну конкретную команду с привилегиями суперпользователя, не переключаясь в его сеанс полностью.

После ввода команды система попросит ввести ваш собственный пароль (не пароль root). Это важно: sudo аутентифицирует именно текущего пользователя, а не суперпользователя.

«ivan is not in the sudoers file» — означает, что ваш пользователь не имеет права использовать sudo. Это не ошибка ввода, а вопрос настройки системы: администратор должен добавить пользователя в список разрешённых. На большинстве десктопных дистрибутивов первый созданный пользователь уже включён в этот список автоматически.

sudo умеет запускать команды не только от root, но и от любого другого пользователя системы. Для этого используется флаг -u. Без флага -u подразумевается root.

Прежде чем выполнять команду с повышенными привилегиями, полезно знать, какие именно команды вам разрешено запускать через sudo. Для этого существует флаг -l.

Запуск sudo -l выводит список правил, которые применяются к текущему пользователю.

Запись (ALL : ALL) ALL означает, что пользователь может выполнять любые команды от имени любого пользователя и любой группы. Это максимально широкие права.

Все эти правила хранятся в файле /etc/sudoers. Именно он определяет, кто и что может делать через sudo. Редактировать его напрямую опасно: синтаксическая ошибка может заблокировать доступ к sudo на всей системе. Поэтому для редактирования используют специальную команду visudo, которая проверяет синтаксис перед сохранением.

`alice   ALL=(root) /usr/bin/apt`
- alice: кому разрешено
- ALL: с каких хостов
- (root): от чьего имени
- /usr/bin/apt: какую команду

Знак % перед именем означает группу (group).

Современные дистрибутивы часто хранят дополнительные правила не в самом /etc/sudoers, а в отдельных файлах внутри директории /etc/sudoers.d/. Это удобно: каждое приложение или роль получает свой файл, и они не мешают друг другу.
