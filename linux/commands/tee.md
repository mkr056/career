Конвейер — это цепочка команд, где данные текут слева направо. Иногда нужно не просто передать данные дальше, но и сохранить промежуточный результат в файл. Именно для этого существует команда tee. tee читает данные из стандартного ввода (stdin), одновременно записывает их в указанный файл и передаёт дальше в стандартный вывод (stdout).

Синтаксис:
`команда | tee файл`
`команда | tee файл | следующая_команда`

По умолчанию tee перезаписывает файл при каждом запуске. Флаг -a (append) добавляет данные в конец, не затирая существующее содержимое.

tee принимает несколько имён файлов через пробел.
