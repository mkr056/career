Когда вы набираете имя команды в терминале, оболочка (shell) должна определить, что именно запустить. Команда type позволяет узнать, как Bash интерпретирует указанное имя.

* Встроенная команда (builtin) — реализована внутри самой оболочки и не является отдельным исполняемым файлом. Примеры: cd, echo, pwd, type. Справку для таких команд можно получить с помощью help имя_команды или man bash.
* Внешняя команда — отдельный исполняемый файл, расположенный в файловой системе. Часто такие программы находятся в /bin, /usr/bin или /usr/local/bin. Для многих внешних команд существуют отдельные страницы man.
* Псевдоним (alias) — другое имя для команды или набора команд. Псевдонимы создаются командой alias и существуют в текущем экземпляре shell. Если определить их в конфигурационном файле, например ~/.bashrc, они будут создаваться снова при запуске Bash.

Флаг -a показывает все найденные варианты, соответствующие указанному имени.

Если одному имени соответствует несколько вариантов, оболочка выбирает один из них согласно правилам поиска команд.

Флаг -t выводит только тип команды одним словом. Возможные значения: builtin, file, alias, function, keyword.
