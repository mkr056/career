Команда `uniq` (от unique) без параметров удаляет повторяющиеся строки в тексте. `uniq` сравнивает только соседние строки. Если одинаковые строки стоят не рядом, она их не тронет.

Флаг `-c` (count) добавляет перед каждой строкой число — сколько раз она встретилась подряд. Одна тонкость формата: `uniq -c` выводит счётчик с ведущими пробелами ( `42 /index`).

Флаг `-d` (duplicated) выводит только те строки, которые встречаются больше одного раза.

Флаг `-u` (--unique) выводит только те строки, которые вообще не повторялись.
