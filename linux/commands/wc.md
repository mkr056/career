wc (word count) — утилита для подсчёта количества строк, слов и символов в тексте.

Базовый синтаксис: `wc [флаги] файл`.

Если запустить wc без флагов, команда выведет сразу три числа. Числа идут в строгом порядке: количество строк — слов — байтов.

На практике чаще нужна одна конкретная цифра, а не все три сразу. Для этого используют флаги:
* -l: количество строк (lines)
* -w: количество слов (words)
* -c: количество байт (bytes/characters)

Если передать несколько файлов, wc выведет статистику по каждому и добавит итоговую строку total.

Флаг -c считает байты, а не символы. Для ASCII-текста это одно и то же, но если файл содержит кириллицу или другие многобайтовые символы UTF-8, результат будет больше числа видимых символов. Чтобы получить именно количество символов (не байт), используют флаг -m.
