Переменная оболочки (shell variable) — это именованная ячейка памяти, в которой хранится текстовое значение. Оболочка bash позволяет создавать такие переменные прямо в терминале, без каких-либо дополнительных инструментов.

Объявить переменную: `ИМЯ=значение`.

Несколько важных правил, нарушение которых приводит к ошибкам:
- Пробелов вокруг знака = быть не должно. Запись ИМЯ = значение не создаст переменную — bash воспримет ИМЯ как команду, а = и значение — как её аргументы.
- Если значение содержит пробелы, его нужно взять в кавычки
- Имена переменных чувствительны к регистру

Чтобы получить значение, перед именем ставится знак $. Команда echo выводит это значение в терминал.

Знак $ говорит оболочке: «подставь сюда значение переменной».

Для надёжности имя переменной внутри строки можно обернуть в фигурные скобки — ${PROJECT}. Это особенно полезно, когда переменная стоит вплотную к другому тексту.

Если переменная не найдена поставляется пустая строка.

Переменная, объявленная описанным способом, существует только в текущем сеансе оболочки (точнее, только в текущем процессе) и недоступна дочерним процессам — программам и скриптам, запущенным из этого терминала. Технически export помечает переменную как часть окружения (environment) — набора пар «ключ=значение», который оболочка передаёт каждому дочернему процессу.

Команда export без аргументов (или export -p) выводит список всех экспортированных переменных текущего сеанса. Флаг -x означает «exported» — переменная передаётся дочерним процессам.

export действует только в рамках текущего сеанса. Как только вы закроете терминал, все экспортированные переменные исчезнут. Чтобы переменная появлялась при каждом входе, её нужно прописать в конфигурационный файл оболочки.

Когда вы вводите в терминале команду ls или git, оболочка не знает заранее, где именно на диске лежит соответствующий исполняемый файл. Вместо того чтобы перебирать всю файловую систему, она обращается к специальной переменной — PATH.

PATH — это переменная окружения, которая содержит список каталогов, в которых оболочка ищет исполняемые файлы. Каталоги перечислены через разделитель — двоеточие (:). Поиск идёт слева направо: оболочка проверяет первый каталог, затем второй и так далее, пока не найдёт файл с нужным именем или не исчерпает список.

Если в двух каталогах из PATH лежат файлы с одинаковым именем, будет запущен тот, чей каталог стоит левее.

Чтобы узнать, какой конкретно файл будет запущен по имени команды, используют команду which.

Добавление нового каталога в PATH: `PATH="$HOME/scripts:$PATH"`. Здесь $HOME/scripts ставится в начало, а $PATH — это старое значение переменной. Двоеточие между ними — тот самый разделитель. После этой команды оболочка будет проверять ~/scripts первым.

Обратите внимание: если написать просто PATH="/home/user/scripts", вы перезапишете всё старое значение. Тогда стандартные команды вроде ls и cd перестанут находиться, потому что /usr/bin и /bin исчезнут из списка.

Изменение, сделанное в терминале напрямую, действует только до конца текущей сессии.
