В Linux все файлы и каталоги организованы в единое дерево. В отличие от Windows, где каждый диск получает свою букву (C:, D:, E:), в Linux есть одна точка входа — корневой каталог (root directory), который обозначается одним символом /. Физически данные могут лежать на разных дисках или разделах, но в файловой системе они всё равно выглядят как ветви одного дерева с корнем /.

Путь — это адрес объекта в дереве файловой системы. Абсолютный путь (absolute path) всегда начинается с / и описывает маршрут от корня. Относительный путь (relative path) не начинается с / и строится от текущего каталога, в котором вы находитесь.

Файловая система Linux — строго организованная структура. Каждая директория верхнего уровня отвечает за конкретный тип данных.
* /home: Личные файлы пользователей
* /etc: Конфигурационные файлы системы
* /var: Изменяемые данные: логи, кэш, очереди
* /tmp: Временные файлы (удаляются при перезагрузке)
* /usr: Программы и данные для всех пользователей
* /bin: Основные исполняемые команды

Обычный пользователь имеет полные права только в своём домашнем каталоге.

Файлы в /etc — текстовые. Вносить изменения в каталог /etc без прав суперпользователя нельзя.

Внутри /usr есть /usr/bin — здесь находятся исполняемые файлы большинства пользовательских команд. /bin хранит самые базовые команды, необходимые для работы системы даже в аварийном режиме: ls, cp, mv, cat, echo. На современных системах /bin часто является символической ссылкой на /usr/bin, но логически их назначение различается: /bin — минимальный набор для выживания системы, /usr/bin — всё остальное.
