nano - это консольный текстовый редактор (console text editor).

Чтобы открыть существующий файл или создать новый, передайте имя файла аргументом.

Если файл существует — nano откроет его содержимое. Если нет — создаст пустой буфер с таким именем; файл появится на диске только после сохранения.

После запуска экран делится на две части: область редактирования сверху и строка подсказок (shortcut bar) снизу. В строке подсказок символ ^ означает клавишу Ctrl. Например, ^O — это Ctrl+O.

Можно выделять текст с помощью Shift и стрелок, а затем вырезать выделенное через Ctrl+K и вставить через Ctrl+U. Отдельно полезна команда Ctrl+K без выделения — она вырезает целую строку целиком.

Когда правки внесены, нажмите Ctrl+O (Write Out — записать файл). Nano покажет строку с именем файла.

Нажмите Enter, чтобы подтвердить имя. Файл будет сохранён, а редактор останется открытым — можно продолжать работу. Если хотите сохранить под другим именем, просто измените имя в строке перед нажатием Enter.

Чтобы закрыть редактор, нажмите Ctrl+X. Если в буфере есть несохранённые изменения, nano спросит сохранить ли измененный буфер. Нажмите Y и Enter — файл сохранится и редактор закроется. Нажмите N — изменения будут потеряны. Ctrl+C отменит выход и вернёт вас в редактор.

Перейдите в конец файла (Ctrl+End или несколько нажатий Ctrl+V для прокрутки вниз), добавьте нужную строку, затем сохраните Ctrl+O → Enter и выйдите Ctrl+X. Изменения вступят в силу после следующего входа в оболочку или выполнения source ~/.bashrc.
