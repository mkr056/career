Пакетный менеджер (package manager) — это инструмент командной строки, который устанавливает, обновляет и удаляет программное обеспечение, автоматически разрешая зависимости. Вместо того чтобы вручную скачивать архив, распаковывать его и прописывать пути, вы отдаёте одну команду — менеджер делает остальное.

В Linux нет единого стандарта: каждое семейство дистрибутивов использует свой инструмент. В DevOps вы будете встречать все три варианта, потому что разные образы Docker и серверы строятся на разных дистрибутивах.

Три семейства и их менеджеры

Alpine особенно важен для DevOps: его образы Docker весят 5–10 МБ против 70+ МБ у Ubuntu, поэтому он стал стандартом для минималистичных контейнеров.

```
# Обновить список доступных пакетов (индекс репозитория)
apt update

# Установить пакет
apt install curl

# Установить несколько пакетов сразу
apt install curl git wget

# Удалить пакет
apt remove curl

# Удалить пакет вместе с конфигурационными файлами
apt purge curl

# Обновить все установленные пакеты
apt upgrade
```

Флаг -y подавляет интерактивный запрос подтверждения — он критически важен в скриптах и Dockerfile: `apt install -y curl`.

yum — классический менеджер, dnf — его современная замена. Синтаксис практически идентичен:

```
# Установить пакет
yum install curl
dnf install curl

# Удалить пакет
yum remove curl
dnf remove curl

# Обновить все пакеты
yum update
dnf upgrade

# Флаг -y работает так же, как в apt
dnf install -y curl
```

```
# Обновить индекс репозитория
apk update

# Установить пакет
apk add curl

# Установить без кеша (важно для Docker-образов)
apk add --no-cache curl

# Удалить пакет
apk del curl
```

Флаг `--no-cache` в Alpine предотвращает сохранение индекса репозитория в образе, что уменьшает его итоговый размер. В Dockerfile для Alpine вы почти всегда будете видеть именно такой вызов.

Перед первой установкой всегда обновляйте индекс.
