В командной строке Linux есть три коротких обозначения путей. Они не являются командами — это специальные символы путей (path shortcuts), которые оболочка раскрывает в конкретные адреса до выполнения команды.
* Одна точка (.) означает «тот каталог, в котором я сейчас нахожусь».
* Две точки (..) — адрес каталога, который находится на уровень выше текущего.
* Тильда (~) — это всегда домашний каталог текущего пользователя (home directory). Для пользователя anna она раскрывается в /home/anna, для root — в /root. То же самое делает cd без аргументов — это равнозначные записи.
