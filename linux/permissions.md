В Linux каждый файл и каталог имеет набор **прав доступа (permissions)**, которые определяют, кто и что может с ним делать. Эта система строится на двух простых идеях: кому принадлежит объект и какие действия разрешены.

Система делит всех, кто может обратиться к файлу, на три категории:
![20261008103832](resources/20261008103832.png)

Когда вы создаёте файл, система автоматически назначает вас его владельцем, а группой становится ваша основная группа.

Для каждой из трёх категорий задаётся набор из трёх битов прав (permission bits):
- r — чтение (read): можно открыть файл и прочитать его содержимое; для каталога — можно получить список файлов внутри.
- w — запись (write): можно изменять содержимое файла; для каталога — можно создавать и удалять файлы внутри.
- x — выполнение (execute): можно запустить файл как программу; для каталога — можно войти в него командой cd.

Если право не предоставлено, на его месте стоит дефис -.

-rwxr-x---
Первый символ (-) означает тип объекта (обычный файл). Дальше идут три группы по три символа:
- rwx — владелец может читать, писать и запускать файл
- r-x — группа может читать и запускать, но не изменять
- --- — остальные не могут делать ничего

Для каталогов бит x означает не запуск, а возможность войти внутрь. Если у пользователя есть r на каталог, но нет x, он увидит список файлов, однако не сможет в него перейти или открыть файлы.
