Bash-скрипт — это обычный текстовый файл, в котором команды записаны построчно. Когда вы запускаете такой файл, оболочка читает его сверху вниз и выполняет каждую команду так, как если бы вы вводили её вручную в терминале. Это и есть суть автоматизации: один файл вместо десятков ручных действий.

Шебанг (shebang, также hashbang) — это специальная первая строка файла: `#!/bin/bash`.

Шебанг #!/bin/bash должен быть именно первой строкой файла — без пустых строк и пробелов перед ней. Даже одна лишняя строка выше сломает механизм определения интерпретатора.

Символы #! сообщают операционной системе, какой интерпретатор использовать для выполнения скрипта. Путь /bin/bash указывает конкретную программу — оболочку Bash. Без этой строки система может запустить скрипт через другой интерпретатор или вовсе отказать в запуске.

$(date) — подстановка команды (command substitution): bash выполняет date и вставляет её вывод прямо в строку echo.

Два способа запустить скрипт:
- Способ 1 — через интерпретатор явно: `bash hello.sh`. Вы передаёте файл напрямую программе bash. Права на выполнение при этом не нужны — bash читает файл как текст.
- Способ 2 — как исполняемый файл:
```bash
chmod +x hello.sh
./hello.sh
```
Сначала командой chmod +x вы выставляете бит выполнения. После этого система сама читает шебанг и запускает /bin/bash. Префикс ./ обязателен: он говорит оболочке искать файл в текущем каталоге, а не в PATH.

 В bash используется условный оператор (conditional statement) if/then/else/fi.

Базовый синтаксис:
```bash
if [ условие ]; then
    # команды, если условие истинно
else
    # команды, если условие ложно
fi
```

Несколько правил, нарушение которых приводит к ошибкам:
- После [ и перед ] обязательны пробелы
- Точка с запятой перед then нужна, если then стоит на той же строке, что и if.
- Блок всегда закрывается словом fi — это if наоборот.

Для проверки равенства двух строк внутри [ ] используется оператор сравнения строк =

Переменную принято брать в двойные кавычки: "$answer". Если переменная окажется пустой или содержит пробелы, без кавычек bash разобьёт её на несколько слов и условие сломается с синтаксической ошибкой. Для проверки неравенства используется !=:

Когда вариантов больше двух, добавляют ветвь elif (сокращение от else if):
```bash
if [ "$color" = "red" ]; then
    echo "Красный"
elif [ "$color" = "blue" ]; then
    echo "Синий"
else
    echo "Неизвестный цвет"
fi
```

[ "10" = "9" ] сравнивает строки, а не числа; для чисел нужен -eq.
